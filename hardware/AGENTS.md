# 硬件设计约定

在本目录设计新板时，按以下偏好出第一版。新项目明确的功能、结构、器件规格和用户决定优先。具体板宽、板厚、电池容量、充电电流、引脚和料号以各板工程为准。

## 从使用方式开始

- 根据当前产品怎么用、怎么安装和装配，确定外形、尺寸、接口位置与外观，并把这些决定记录在对应工程。用实际器件的最大尺寸和装配所需空间排布，通过有尺寸的 CAD 视图核对板壳配合、插拔空间和元件高度。
- 先画供电和信号框图，再画一页可读的模块化原理图。模块内能直接连接的引脚就画线，跨区长线用同名网络标签并标明用途。查原厂手册、参考原理图和立创开源板，确认模组已集成的功能、实际引出的引脚、外围器件和天线要求。

## 选料、电源和烧录

- 同步查嘉立创国内 SMT 可贴库存、单价、基础库或优选标记和换料费。优先复用同一料号。阻容优先 0402；电容还要核对工作电压下的有效容量，电阻还要核对功耗和精度。有电气或采购依据时选 0603、0805。为共料改阻值前，先重算它所设定的电流、电压或门限。
- 电池产品按实际工作状态的电流与持续时间做续航预算。核算供电器件和各外设的待机电流，再决定是否需要断电。按本板支持的供电方式复核低电量、外部供电和充电行为，用首板实测验证预算。
- 需要烧录固件的板要给首次烧录留出操作空间。探针焊盘的排列、直径和间距按实际夹具确定。丝印写清板端信号名，电源接口在插接面标明用途和极性。

## 摆件和布线

- 优先两层板、元件集中正面，按经济型单面贴片核算整单成本。完整摆好阻容、接口、测试点和安装件后再布线。相同阻容尽量对齐，去耦电容靠近对应电源脚并缩短地回路。
- 优先 0.30 mm 钻孔的过孔。信号线通常用水平、垂直和 45° 转角，能拉直的就拉直。密集处可评估 0.10 mm 信号线，结合板厂能力、裕量和成本决定。电源、差分线和射频线按各自的电流、阻抗和回流要求设计。
- 按所用芯片或模组的参考设计处理天线匹配、板边位置和各层净空。敏感音频信号避开天线区域，保持回流连续；两面铺地时保留禁铜区。泪滴按实际工艺需要使用，默认不批量添加。
- 窄处难布时，先看测试点、器件方向、出线顺序和回流，必要时比较几次布线结果。确实需要背贴、加宽外壳或增加层数时，给出尺寸、工艺和费用影响，让用户决定。

## 交付与打样

- 从当前 KiCad 工程导出真实摆件图和铺铜后的正反面走线图，标明背面视角与接口方向。打样前复核原理图与器件手册，重新铺铜，运行 ERC、DRC 和原理图一致性检查。
- 单独给出 Gerber（含钻孔）、贴片 BOM 和坐标 CPL。核对 BOM 与 CPL 的位号、贴装面和极性器件方向。手焊件保留在整板 BOM，从贴片 BOM 与 CPL 同时排除。
- 板目录提供可直接打开的 KiCad 工程，配套原理图、PCB、符号库和封装库。用户确认替换的旧试排和旧打样包及时清理。每次给出当前打样目录和实际下单参数，标明需由样机确认的项目。
